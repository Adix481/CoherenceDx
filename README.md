# 🧬 CoherenceDx
## Hybrid Quantum Machine Learning Platform for Early Disease Detection

CoherenceDx is an end-to-end machine learning and quantum machine learning platform designed to explore the application of **Classical Machine Learning, Quantum Machine Learning (QML), and Hybrid Quantum-Classical Learning** for early disease prediction.

The project focuses on two healthcare prediction tasks:

- 🫀 Heart Disease Prediction
- 🎗️ Breast Cancer Prediction

The platform provides a unified environment where Classical SVM, Quantum Variational Quantum Classifier (VQC), and Hybrid Quantum-Classical models can be trained, evaluated, compared, and used for inference through an interactive web application.

> ⚠️ **Research Prototype:** CoherenceDx is an academic/research project and is not intended to replace professional medical diagnosis, clinical testing, or healthcare professionals.

---

## 🚀 Project Overview

Early identification of potential disease risk can help healthcare professionals determine whether further clinical investigation may be appropriate.

CoherenceDx explores whether quantum and hybrid quantum-classical approaches can be integrated into conventional machine learning pipelines for healthcare prediction.

Rather than assuming that quantum models will automatically outperform classical models, the project provides a **controlled comparison between Classical, Quantum, and Hybrid approaches** using the same overall prediction framework and evaluation metrics.
